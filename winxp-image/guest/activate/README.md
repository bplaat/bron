# confid

Offline Windows XP confirmation ID generator from [UMSKT](https://github.com/UMSKT/UMSKT), licensed under the AGPL
(see [LICENSE](LICENSE)).

Vendored files: `src/libumskt/confid/confid.cpp`, `confid.h` and `src/typedefs.h` (renamed to `umskt-typedefs.h`).
`main.cpp` provides the command-line wrapper used by `../activate.vbs` during guest setup.
