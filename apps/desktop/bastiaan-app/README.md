# Bastiaan

My personal website as a native app, built with [bwindow](../../../lib/ui/bwindow) and
[bcanvas](../../../lib/graphics/bcanvas). It runs on Windows XP too, where the
[Windows XP desktop](../../web/bastiaan/winxp-image) of the website starts it at logon.

## Features

- Website content with links that open in the browser
- Animated background particles
- Native scrolling
- TinyVG icons and a high-DPI avatar
